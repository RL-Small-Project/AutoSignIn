# Excel 檔案模板說明

請手動建立以下格式的 Excel 檔案：

## 檔案名稱範例
- `3A.xlsx` (3年A班)
- `2B.xlsx` (2年B班)

## 工作表名稱
- 工作表名稱必須為: `點名單`

## 欄位格式範例

| 姓名   | 學號     | 2025-11-11 | 2025-11-12 | ... |
|--------|----------|-----------|-----------|-----|
| 王小明 | 11001    | 遲到      |          |     |
| 李大華 | 11002    | 曠課      | 缺遲      |     |
| 張美麗 | 11003    |           | 遲到      |     |
| 陳小英 | 11004    | 缺節      |          |     |

## 重要說明
1. **必要欄位**: `姓名`, `學號`
2. **日期欄位**: 使用 YYYY-MM-DD 格式作為欄位標題
3. **狀態值**:
   - 空值或空白 = 正常出席
   - `遲到` = 遲到
   - `曠課` = 曠課 (兩節都缺席)
   - `缺節` = 缺席一節課
   - `缺遲` = 缺席+遲到

## 範例資料
```
姓名: 王小明, 學號: 11001
2025-11-11: 遲到 (第一節遲到)

姓名: 李大華, 學號: 11002  
2025-11-11: 曠課 (兩節都缺席)
2025-11-12: 缺遲 (第一節缺席，第二節遲到)

姓名: 張美麗, 學號: 11003
2025-11-11: (空白，表示正常出席)
2025-11-12: 遲到 (第一節遲到)
```

請將此檔案放置於 `data/` 目錄中。
